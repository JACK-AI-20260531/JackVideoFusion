# PRD: jack-video-fusion(AI智剪工坊)

## Executive Summary
面向短视频矩阵运营、影视解说博主、自媒体工作室和个人博主的 Windows 桌面端 AI 批量视频混剪工具。依托文件夹素材隔离机制、本地 CLIP + 云端 LLM 双 AI 模式、完全免费的微软 TTS 引擎,实现素材处理、智能混剪、AI 成片、配音字幕、多平台自动发布的全流程自动化。V1.0 聚焦基础可用(框架 + 混剪双模式 + 素材处理 + 通用能力),V1.1 引入 AI 增强,V1.2 完成语音克隆与多平台自动发布。

## Problem Statement
- 短视频批量制作效率低,人工剪辑成本高
- 画面匹配依赖人工筛选,精准度差
- 商用 TTS 付费额度受限,且多有字符数 / 时长上限
- 现有工具多云端处理,创作者素材隐私难以保障
- 影视解说等二次创作缺自动化"节奏复刻"能力

## User Stories
- **US-1 矩阵运营**:作为短视频矩阵运营,我希望一次配置多文件夹素材,自动批量生成差异化带货视频,以便覆盖多个账号分发。
- **US-2 影视解说博主**:作为影视解说博主,我希望导入参考解说视频,系统自动复用其镜头节奏并替换为我的自有素材,以便规避同质化。
- **US-3 工作室批量创作者**:作为工作室成员,我希望排队提交多个混剪任务,自动依次完成、断点续渲染,以便规模化量产。
- **US-4 个人博主**:作为个人博主,我希望使用完全免费的微软 TTS 一键生成 5W 字符解说音频 + SRT 字幕,以便零成本完成配音。
- **US-5 隐私敏感用户**:作为注重隐私的用户,我希望所有素材在本地处理、不上传云端,以便安全使用自有版权素材。

## Functional Requirements

### 4.1 素材处理模块
- **FR-4.1.1 素材分割**:按时长固定分割 / 按镜头智能分割;支持自定义单片段时长、保留原画质、去除原声、批量命名、自动归档。
- **FR-4.1.2 文本分割**:超长文案按字数切分;支持保留标点、自动分段、批量导出 TXT。
- **FR-4.1.3 微软免费 TTS 合成**(核心):基于 Edge-TTS;支持粘贴文本 / 导入 TXT / SRT;语速、音量、音调、多音色、男女声;**单次支持 5W 字符、1 分钟以上长音频**;同步生成 SRT 字幕;逐行配音、批量合成。
- **FR-4.1.4 语音克隆**(V1.2 迭代):少量样本训练专属音色,用于 TTS 合成。
- **FR-4.1.5 字幕提取**:批量解析视频内嵌字幕,生成 SRT;支持纠错与手动编辑。

### 4.2 视频混剪模块
- **FR-4.2.1 随机素材混剪**:多文件夹排序,每个文件夹按设定数量随机抽取片段,按序拼接;支持片段数、总时长、不重复复用、分辨率、水印/字幕开关、自动淡化转场、统一画面比例。
- **FR-4.2.2 文件夹音频匹配合成**:单文件夹内随机抽 1 条音频 + 同文件夹随机视频素材合成独立片段;文件夹间不交叉;支持去原声、背景音乐淡入淡出、音频循环适配视频时长。

### 4.3 AI 剪辑模块
- **FR-4.3.1 文件夹隔离机制**:音频仅匹配同文件夹视频素材,代码层强制。
- **FR-4.3.2 双 AI 推理模式**:本地 CLIP(ONNX Runtime,离线)/ 云端 LLM(OpenAI / 通义 / Ollama,可自定义地址与密钥)。
- **FR-4.3.3 全自动成片**:解析音频时长 + 字幕时间轴 + 文案 → 语义筛选画面 → 适配音频节奏切镜 → 叠加字幕/配音/水印 → 导出。

### 4.4 AI 切片剪辑模块
- 批量导入长视频,AI 识别精彩片段/卡点/分割点,自动去冗余,批量输出差异化短视频。

### 4.5 影视解说克隆模块
- 解析参考视频镜头节点 / 时长 / 转场节奏;提取剪辑特征序列;匹配自有素材;复刻节奏 + 替换画面 + 自定义配音字幕;批量生成差异化解说。

### 4.6 自动发布模块(V1.2)
- 多平台账号管理(抖音 / 快手 / 小红书 / 视频号 / B 站);批量上传、自定义标题/话题/封面、定时发布、任务队列、运行状态日志;含风险提示。

### 4.7 通用全局功能
- 分辨率自定义(720P / 1080P / 4K,原画质无损)
- 图片 / 文本水印(位置、透明度)
- 字幕字体 / 大小 / 颜色 / 样式 / 自动排版
- 任务队列:排队、暂停、终止、断点续渲染
- 实时日志输出
- 全部导出路径可自定义

## Non-Functional Requirements
- **性能**:多任务排队,单次混剪在常规素材下可完成断点续渲染
- **可用性**:深色主题;左侧导航 + 主功能区 + 底部日志;功能模块可切换、高亮当前
- **兼容性**:Windows 10/11 64 位;素材格式 MP4 / MOV / MP3 / TXT / SRT
- **可维护性**:技术栈统一(见 5.1),模块边界清晰,文件夹隔离规则在代码层固化
- **合规**:启动页 / 关于页免责声明;文案禁用"去重 / 规避查重 / 搬运";遵循微软 TTS 开源协议

## Success Criteria
- 所有功能可正常打开、运行、导出,**无闪退、无卡死、无报错**
- **文件夹隔离规则 100% 生效**,音频仅匹配同文件夹素材
- 微软 TTS **单次支持 5W 字符**长文本合成,无截断 / 无乱码 / 无时长限制
- 本地 AI 模式可完全离线运行,无需联网
- LLM 大模型模式可对接第三方接口,优化画面匹配
- 成片画质清晰、音画同步、字幕匹配准确

## Constraints & Assumptions
- 技术栈固定:Electron + Vue3 + FFmpeg + ONNX Runtime(CLIP) + Edge-TTS + PySceneDetect
- 仅支持 Windows 桌面端(暂不考虑 macOS / Linux)
- 离线场景下,LLM 增强模式不可用
- Edge-TTS 服务可用性依赖微软 Edge 接口稳定性
- 多平台自动发布依赖第三方平台开放接口,合规风险由用户承担

## Out of Scope(V1.0 / V1.1)
- 语音克隆(V1.2)
- 多平台自动发布(V1.2)
- 视频特效 / 滤镜编辑器 / 高级时间线剪辑(非工具定位)
- 移动端 / Web 端

## Dependencies
- FFmpeg(本机或内置)
- ONNX Runtime + CLIP 模型权重
- Edge-TTS Node SDK
- PySceneDetect(镜头检测,可本地 Python 进程或预计算)
- 第三方 LLM API(可选,云端模式)
- 各短视频平台开放接口(V1.2 自动发布)
