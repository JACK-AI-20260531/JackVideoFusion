# Task: FFmpeg IPC 服务封装

## Description
封装 FFmpeg 为统一 IPC 服务,提供分割、抽帧、拼接、转码、滤镜、水印、字幕烧录等原子能力。所有混剪 / 素材处理 / 自动发布模块都通过此服务调用,禁止散落 `exec`。

## Acceptance Criteria
- [ ] `ffmpeg-service` 暴露原子方法:`probe / split / extractFrames / concat / remux / transcode / applyWatermark / burnSubtitle / stripAudio / getDuration / getMetadata`
- [ ] 每个方法返回结构化结果(成功/失败/输出路径/时长/进度回调)
- [ ] 进度通过 `webContents.send('ffmpeg:progress', ...)` 推送
- [ ] FFmpeg 二进制随包(NSIS 内置)或 PATH 检测,启动时校验可用性
- [ ] 单元测试覆盖至少 5 个核心方法

## Technical Details
- 使用 `fluent-ffmpeg` + Promise 包装
- 长任务必须支持 `cancel(token)`
- 失败统一抛 `FFmpegError`(含 stderr 摘要)
- 目录约定:`src/main/services/ffmpeg/`
