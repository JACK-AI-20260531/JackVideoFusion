# Task: 素材处理模块 UI + 服务(分割/文本分割/字幕提取)

## Description
实现素材处理模块 V1.0 三个核心功能:素材分割、文本分割、字幕提取。

## Acceptance Criteria
- [ ] **素材分割**:按时长固定分割 + 按镜头智能分割(基础版:按固定时长即可,镜头检测留给 V1.1);参数:单片段时长、保留原画质、去原声、命名规则、自动归档
- [ ] **文本分割**:按字数切分,保留标点,自动分段,批量导出 TXT
- [ ] **字幕提取**:批量解析 MP4/MOV 内嵌字幕流,生成 SRT;支持纠错与手动编辑
- [ ] 三个子功能在 UI 中 Tab 切换,均可入队任务队列
- [ ] 实时日志 / 进度条可视化
- [ ] 失败时明确报错提示

## Technical Details
- 分割:`ffmpeg-service.split`
- 字幕提取:`ffmpeg-service.extractSubtitle`(基于 `ffmpeg -i ... -map 0:s:0`)
- 文本分割:纯 Node 字符串处理,标点感知
- 目录约定:`src/renderer/views/material-process/` + `src/main/services/material-process/`

## Dependencies
- 003(FFmpeg 服务)
- 004(素材仓库与文件夹隔离)
