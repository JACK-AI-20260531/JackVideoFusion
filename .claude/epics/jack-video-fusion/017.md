# Task: 多平台自动发布(Playwright 浏览器自动化)

## Description
实现抖音/快手/小红书/B站四大平台的视频自动发布。采用 Playwright 控制系统浏览器,模拟用户登录上传:首次扫码登录后持久化 cookie,后续批量上传无需重复登录。支持自定义标题/话题/封面、定时发布、任务队列、运行状态日志。含合规风险提示。

## Acceptance Criteria
- [ ] **账号管理**:4 平台首次扫码登录;cookie 持久化(userData/auth/);登录状态检测;一键退出
- [ ] **视频上传**:每个平台实现上传器,填写标题/话题/封面/描述,选择视频文件,提交发布
- [ ] **批量发布**:多视频 × 多平台组合;任务队列排队;支持暂停/取消/重试
- [ ] **定时发布**:设置发布时间;到点自动执行(任务队列 checkpoint)
- [ ] **状态日志**:实时输出每个上传步骤(登录中/上传中/发布中/成功/失败);失败原因可读
- [ ] **合规提示**:启动页 + About + 首次使用弹窗,明确"遵守各平台运营规则,风险自负"
- [ ] **AutoPublishView 完整功能页**:从占位页升级为完整 UI

## Technical Details
- **架构**:Electron 主进程通过 `playwright-core` 启动系统 Chromium(用户已安装的浏览器,避免重复下载),`persistContext` 持久化登录态
- **平台适配器**:`PlatformAdapter` 抽象接口,每平台一个实现类,封装登录/上传/发布流程
- **目录约定**:
  - `src/main/services/auto-publish/` — 服务层
    - `adapters/` — 各平台适配器(douyin/kuaishou/xiaohongshu/bilibili)
    - `browser-manager.ts` — Playwright 浏览器管理
    - `publish-queue.ts` — 发布任务队列(复用 task-queue)
    - `auth-store.ts` — 登录态持久化
  - `src/main/ipc/auto-publish.ipc.ts` — IPC 通道
- **API 接口**:
  - `auto-publish:login(platform)` — 打开浏览器扫码登录
  - `auto-publish:checkLogin(platform)` — 检查登录状态
  - `auto-publish:logout(platform)` — 退出登录
  - `auto-publish:publish(params)` — 发布视频(可批量)
  - `auto-publish:cancel(taskId)` — 取消发布任务
  - `auto-publish:listAccounts` — 列出已登录账号
- **依赖**:`playwright-core`(不下载浏览器,用系统 Chrome/Edge)
- **风险控制**:上传频率限制(默认每平台每分钟 1 条);敏感词检测(标题/描述)
