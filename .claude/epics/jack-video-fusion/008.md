# Task: 视频混剪双模式(随机混剪 + 文件夹音频匹配)

## Description
实现 PRD 4.2 两大混剪模式,体现文件夹隔离核心差异化。

## Acceptance Criteria
- [ ] **模式一 随机素材混剪**:多文件夹按顺序,每个文件夹按设定数量随机抽取片段,按序拼接;参数:单文件夹抽取数、总时长、不重复复用、分辨率、水印/字幕开关、自动淡化转场、统一画面比例
- [ ] **模式二 文件夹音频匹配合成**:单文件夹内随机抽 1 条音频 + 同文件夹随机视频素材合成独立片段;文件夹间不交叉;支持去原声、背景音乐淡入淡出、音频循环适配视频时长
- [ ] 两个模式 UI 入口独立;输出可自定义路径
- [ ] 全部走任务队列,支持暂停 / 终止 / 断点续渲染
- [ ] 集成水印 + 字幕(009 通用能力)
- [ ] 验收:同一文件夹模式 100 次运行,跨文件夹调用 0 次

## Technical Details
- 模式一:多文件夹顺序队列 + `material-repo.pickFromFolder`
- 模式二:folder 维度独立子任务,最后 concat
- 画面比例统一:`scale + pad` 滤镜
- 转场淡化:`xfade` 滤镜(可后续替换)
- 目录约定:`src/renderer/views/video-mix/` + `src/main/services/video-mix/`

- 005(任务队列)
- 007(素材处理)
