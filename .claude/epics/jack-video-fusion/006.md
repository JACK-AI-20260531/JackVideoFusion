# Task: 微软 Edge-TTS 服务与 SRT 生成

## Description
基于 `edge-tts` Node SDK 实现 TTS 服务,**硬性要求单次支持 5W 字符超长文本合成、1 分钟以上长音频生成**,自动生成对应 SRT 字幕。

## Acceptance Criteria
- [ ] 支持粘贴文本 / 导入 TXT / SRT
- [ ] 参数:语速、音量、音调、多音色(男女声切换)
- [ ] 5W 字符超长文本一次性合成成功,无截断 / 无乱码 / 无时长限制
- [ ] 1 分钟以上长音频可一次性合成
- [ ] 自动生成 SRT 字幕,逐行配音,时间轴与音频对齐
- [ ] 批量合成:多段文本一次性排队输出
- [ ] 失败时清晰报错(网络、字符、引擎错误分类)
- [ ] 单测 + 5W 字符合成烟雾测试通过

## Technical Details
- 长文本内部按句号/段落切片,流式接收 mp3,按切片边界切分 SRT
- 字幕时长 = 字数 × 单字时长(经验值,可校准)
- 失败重试 2 次,指数退避
- 目录约定:`src/main/services/tts/`

## Dependencies
- 003(FFmpeg 服务)

## Effort Estimate
- Size: L
- Hours: 12-16

## Definition of Done
- [ ] 5W 字符合成端到端验证(产物可播放、SRT 同步)
- [ ] 批量合成 10 段文本无丢失
- [ ] 代码含函数级注释
