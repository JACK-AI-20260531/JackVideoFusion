# Task: 项目骨架与全局布局

## Description
搭建 Electron + Vue3 工程骨架,实现左侧固定导航 + 右侧主功能区 + 底部日志栏的深色主题全局布局,完成 7 个模块路由与 IPC 通信基座。

## Acceptance Criteria
- [ ] Electron 主进程可启动,渲染进程加载 Vue3 应用
- [ ] `vue-router` 注册 7 个模块路由(素材处理/视频混剪/AI剪辑/AI切片/影视解说克隆/自动发布/系统设置)
- [ ] 全局布局三段式:左侧固定导航(选中高亮)、主功能区(可滚动)、底部日志栏(可折叠)
- [ ] 深色主题统一变量(色板、间距、圆角、阴影),对标 VideoFusion 视觉风格
- [ ] Pinia 安装并初始化 4 个 store(useMaterialStore/useTaskStore/useLogStore/useConfigStore)
- [ ] 启动页 / About 弹窗植入免责声明
- [ ] 全部 UI 文案审查不出现"去重/规避查重/搬运"等违规词
- [ ] Windows 10/11 x64 启动 < 5s

## Technical Details
- 渲染层:Vite + Vue3 + TypeScript + Pinia + vue-router
- 主进程:Electron 28+,preload 暴露 `window.api` 命名空间
- 样式:Less 变量驱动;避免散落硬编码
- 目录约定:`src/renderer/{views,components,stores,router,styles}` + `src/main/{services,ipc,db}`
- IPC 基座:统一 `ipcMain.handle('service:method', handler)` 模式
