# Task: 通用能力(水印/字幕/分辨率/日志面板)

## Description
实现所有模块共享的通用能力:水印(图片+文本)、字幕(字体/大小/颜色/样式)、分辨率(720P/1080P/4K)、实时日志面板、断点续渲染、路径自定义。

## Acceptance Criteria
- [ ] **水印**:图片 / 文本水印;位置(九宫格 + 自定义坐标)、透明度(0-100)、实时预览
- [ ] **字幕**:字体(系统字体 + 自定义 ttf)、大小、颜色、描边、阴影、对齐、自动排版
- [ ] **分辨率**:720P/1080P/4K,原画质无损导出选项
- [ ] **日志面板**:实时输出运行日志、进度条、报错信息;支持按任务/模块过滤、清空、导出
- [ ] **路径自定义**:全部导出文件路径可配置,默认值在 `useConfigStore`
- [ ] 与 FFmpeg 服务、任务队列深度集成

## Technical Details
- 水印:`ffmpeg overlay` 滤镜
- 字幕烧录:`subtitles=...:force_style=...` 滤镜
- 日志:winston + IPC 广播
- 路径:`app.getPath('userData')/exports/...` 默认
- 目录约定:`src/renderer/components/{WatermarkEditor,SubtitleEditor,LogPanel}` + `src/main/services/common/`

- 003(FFmpeg 服务)
