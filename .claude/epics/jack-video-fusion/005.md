# Task: 任务队列(排队/暂停/终止/断点续渲染)

## Description
基于 SQLite + 状态机实现统一任务队列,支持排队、暂停、终止、断点续渲染。

## Acceptance Criteria
- [ ] 任务状态机:`pending → running → paused → completed | failed | cancelled`
- [ ] IPC 暴露:`task.enqueue / task.pause / task.resume / task.cancel / task.list / task.get`
- [ ] 断点续渲染:每个原子步骤落 checkpoint(FFmpeg 进度百分比 + 下游任务输入)
- [ ] 同一时刻 1 个 running 任务(避免 GPU/磁盘抢占),可配置并发数(默认 1)
- [ ] 启动时自动恢复 `running → paused` 状态(进程崩溃兜底)
- [ ] 队列可承载 50+ 任务,UI 不卡顿

## Technical Details
- 状态机纯函数 `transition(currentState, event): nextState`
- 进度通过 EventBus 推送到 LogPanel
- 目录约定:`src/main/services/task-queue/`
