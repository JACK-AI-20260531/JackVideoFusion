# Task: 语音克隆服务(GPT-SoVITS 集成)

## Description
集成开源 GPT-SoVITS 模型,支持用户上传 5-10 秒样本即可克隆专属音色,用于 TTS 合成。采用 API server 模式:GPT-SoVITS 作为独立 Python 服务运行,Electron 主进程通过 HTTP 调用,避免复杂的 Python 嵌入。克隆音色可在素材处理-TTS 模块和影视解说克隆模块中使用。

## Acceptance Criteria
- [ ] **音色样本管理**:上传音频样本(5-30s)、试听、命名、删除;音色库持久化
- [ ] **音色克隆**:一键克隆(zero-shot,无需训练);克隆后音色可立即用于 TTS 合成
- [ ] **克隆 TTS 合成**:输入文本 + 选择克隆音色 → 生成配音音频 + SRT 字幕;支持长文本(5W 字符)
- [ ] **GPT-SoVITS 服务管理**:自动检测/启动/停止 GPT-SoVITS API server;健康检查;端口冲突处理
- [ ] **降级策略**:GPT-SoVITS 未安装/未启动时,UI 明确提示并降级到 Edge-TTS
- [ ] **音色库 UI**:在素材处理-TTS Tab 增加"克隆音色"选项;设置页增加"音色库管理"
- [ ] 与现有 TTS 服务接口兼容(cloneVoice 参数可替代 edgeVoice)

## Technical Details
- **架构**:GPT-SoVITS 官方 `api_v2.py` 作为独立 Python 子进程,监听 `http://127.0.0.1:9880`
- **Electron 集成**:`voice-clone-service` 通过 `child_process.spawn` 启动 GPT-SoVITS server,HTTP 客户端调用推理接口
- **音色库存储**:`userData/voice-library/` 目录,每个音色含 `meta.json` + `sample.wav` + `referrer.wav`
- **API 接口**:
  - `voice-clone:cloneSample` — 上传样本,生成克隆音色(zero-shot)
  - `voice-clone:synthesize` — 用克隆音色合成 TTS
  - `voice-clone:listVoices` — 列出音色库
  - `voice-clone:deleteVoice` — 删除音色
  - `voice-clone:checkService` — 检查 GPT-SoVITS 服务状态
  - `voice-clone:startService` — 启动 GPT-SoVITS server
- **目录约定**:`src/main/services/voice-clone/` + `src/main/ipc/voice-clone.ipc.ts` + `src/renderer/views/voice-clone/`
- **依赖**:用户需本地安装 GPT-SoVITS(Python 3.10+),首次启动引导
