## 1. 快速开始

### 1.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 64 位及以上 |
| Node.js | 24.x(开发者) |
| 磁盘空间 | ≥ 2 GB(含 ffmpeg、onnxruntime 等依赖) |
| 内存 | ≥ 8 GB(AI 剪辑/语音克隆建议 16 GB) |
| 网络 | 微软 TTS、LLM、自动发布需联网;本地剪辑离线可用 |

### 1.2 安装与启动

**普通用户(安装包)**:
1. 双击 `JackVideoFusion-2.2.0-x64.exe`
2. 按向导完成安装,勾选"创建桌面快捷方式"
3. 从开始菜单或桌面图标启动

**开发者(源码运行)**:
```bash
# 安装依赖
npm install

# 开发模式(完整 Electron 应用)
npm run dev:electron

# 生产构建
npm run build:electron

# 打包 Windows 安装包
npm run package:win
```

### 1.3 首次启动

首次启动会显示**免责声明**页,阅读后点击「我已阅读并同意」进入主界面。免责声明要点:
- 用户需自行保证素材版权合法
- 遵循微软 TTS 开源协议,不剥离/单独售卖语音能力
- 所有素材处理在本地完成,不上传云端
- 自动发布需遵守各平台规则,违规后果自负

## 3. 素材处理

进入「素材处理」模块,顶部有 4 个 Tab:素材分割、文本分割、微软TTS、字幕提取。

### 3.1 素材分割

按固定时长将单个视频分割为多个片段。

**操作步骤**:
1. 点击「选择」或拖拽视频文件到输入框(支持 mp4/mov/avi/mkv/flv)
2. 选择输出目录
3. 设置**单片段时长**(秒,默认 10)
4. 设置**命名规则模板**(默认 `{name}_{index}`)
5. 按需勾选「保留原画质」「去原声」
6. 点击「开始分割」,实时查看进度
7. 完成后查看分割结果列表

**示例**:输入 `解说.mp4`,时长 60 秒,设单片段 10 秒,输出 6 个文件:`解说_1.mp4` ~ `解说_6.mp4`。

### 3.2 文本分割

按字数切分长文本,批量导出为 TXT。

**操作步骤**:
1. 点击「导入 TXT」或直接粘贴文本到文本框
2. 设置**单条最大字数**(默认 100)
3. 按需勾选「保留标点」「自动分段」
4. 点击「开始分割」
5. 查看分割结果(每条片段 + 字数)
6. 点击「导出 TXT」下载合并文件

### 3.3 微软 TTS

基于微软 Edge TTS 合成中文语音,可同步生成 SRT 字幕。

> **无需任何配置**:微软 TTS 走微软免费的 Edge 语音端点,**不需要 API Key、账号或申请**,只需联网即可用。相比需要自建/自备服务的语音克隆,可直接使用开箱即用。

**操作步骤**:
1. 选择**音色**(6 种内置:晓晓/云健等,男女声各 3 种)
2. 拖动滑块调整**语速**(-100~100)、**音量**(0~100)、**音调**(-100~100)
3. 选择输出目录
4. 按需勾选「同时生成 SRT 字幕」
5. 导入 TXT 或粘贴文本(查看字符计数,**上限 5 万字**)
6. 点击「开始合成」,查看音频/字幕输出路径

### 3.4 字幕提取、OCR 画面识别与语音转写

批量提取视频内嵌字幕流,生成 SRT 文件。

**操作步骤**:
1. 点击「批量选择」添加多个视频文件
2. 在文件列表中可移除单个文件
3. 选择输出目录
4. 如视频无内嵌字幕流,可在「无字幕流时」下拉选择识别方式:
   - **跳过**(默认):不额外处理
   - **OCR 识别画面文字**:自动逐帧识别画面中烧录的文字并生成 SRT(首次需联网下载识别引擎语言包,之后离线可用)
   - **语音识别人声**:基于 Whisper 本地模型识别视频中人声并生成 SRT(首次需联网下载语音模型,之后离线可用;模型缓存于本机)
5. 点击「开始提取」
6. 查看每个文件状态:
   - ✓ 成功:已提取字幕
   - ✕ 失败:提取出错
   - — 无字幕流且识别方式为「跳过」时忽略 / OCR 未识别到文字 / 语音识别未识别到内容时报错
7. 查看顶部「成功/失败/共」汇总

> 提示:语音识别(ASR)相比画面 OCR,更适合识别**解说、旁白、对白**等口播内容;OCR 更适合识别**烧录在画面里的硬字幕**。两者本地运行,不上传音视频数据。

## 4. 视频混剪

两种混剪模式,通过顶部 Tab 切换。均支持**暂停/恢复**与**断点续渲染**。

### 4.1 随机素材混剪

从多文件夹随机抽取片段拼接成新视频,支持转场淡化。

**操作步骤**:
1. 点击「+ 添加文件夹」添加 1 个或多个素材文件夹
2. 设置抽取参数:
   - 每文件夹抽取片段数(默认 3)
   - 目标总时长(0=不限)
   - 单片段时长(秒,用于切短分段,0=不切)
   - **转场淡化**(秒,0=无转场,>0 启用 xfade 链式转场,如 fade/wipeleft/dissolve 等)
3. 设置输出参数(分辨率、目录、文件名)
4. 按需配置 TTS 配音、字幕、水印
5. 点击「开始混剪」

**运行中操作**:
- 点击「暂停」可中断当前 ffmpeg 进程,任务状态变为「已暂停」,中间产物(checkpoint)保留
- 点击「恢复」从最近 checkpoint 继续,自动跳过已完成的选取/拼接/缩放/水印/字幕步骤
- 点击「取消」彻底终止任务并清理

### 4.2 文件夹音频匹配

每个文件夹用其对应的音频配视频合成,支持背景音乐淡入淡出。

**操作步骤**:
1. 添加文件夹(每个文件夹应含视频和对应音频)
2. 设置抽取参数:
   - 每文件夹抽取视频条数(默认 3)
   - 是否去除原视频声音(默认是)
   - **背景音乐淡入淡出**(秒,默认 0.5;会同时应用淡入与淡出)
   - 音频是否循环适配视频时长(默认是)
3. 设置输出参数
4. 按需配置水印
5. 点击「开始匹配混剪」

**断点续渲染**:与随机混剪相同,暂停后可从最近完成的文件夹继续,已合成的片段不会重复处理。

### 4.3 混剪参数模板(v2.1)

把当前「随机素材混剪」页的全部参数(文件夹选择、抽取参数、水印/字幕等)保存为命名模板,下次一键套用。

- **存为模板**:配置好参数后,在页面顶部「参数模板」条输入名称,点击「📌 存为模板」
- **套用**:下拉选择模板 → 点击「套用」,所有表单项自动写回
- **删除**:选中模板后点击「删除」
- 同名保存即覆盖;模板落盘于本地 `userData/mix-templates/templates.json`

### 4.4 语义搜索与自动标签(v2.1)

视频混剪页顶部内置**素材语义搜索条**,用自然语言直接找素材:

- **建索引**:点击「重建索引」,后台为全部素材逐个抽帧 → CLIP 向量化(进度见任务中心;已索引素材自动跳过,可反复触发增量补齐)
- **搜索**:输入描述文字(如「海边日落空镜」「室内产品展示」)→ 回车或点「搜索」,返回最相似的素材列表(文件名 + 自动标签 + 所属文件夹 + 相似度)
- **自动标签**:建库时按预设词表(场景/主体/风格)自动为每个素材打 3 个语义标签
- **标签筛选**:搜索结果可用下拉按自动标签过滤(v2.2)
- **语义查重**:两两余弦近重复分组,一键移除冗余
- 索引落盘于本地 `userData/semantic/semantic-index.json`

### 4.5 素材清单模式(v2.2)

不按文件夹随机抽取,而是把**显式素材列表**直接送进混剪流水线:

- **入口一(推荐)**:热点选题页生成脚本后点「语义推荐素材」→ 勾选命中 → 点「一键进混剪」,自动带着所选素材跳转到本页并进入清单模式
- **清单管理**:每条可单独「移除」,点「退出清单模式」清空并回到文件夹随机抽取
- 清单中的素材逐条参与切分/拼接/水印/字幕等全部流水线,其余参数(切分时长、分辨率、水印等)与随机混剪完全一致

## 5. AI 剪辑

输入解说文案,LLM 抽取关键词 + CLIP 语义匹配画面,自动切镜合成成片。

### 前置条件

- **必须配置 LLM**(系统设置 → LLM 配置):
  - Provider:openai / qwen / ollama / custom
  - 接口地址、API Key、模型名
  - ollama 允许空 API Key
- 若未配置,页面顶部显示黄色警告,无法开始

### 操作步骤

1. **输入解说文案**:按句号或换行分段,每段匹配一个画面
2. 可点击「预览关键词」验证 LLM 抽取效果
3. **添加素材文件夹**:点击「+ 添加文件夹」,单选一个文件夹作为画面来源(可刷新素材数)
4. **设置输出参数**:
   - 分辨率(720p/1080p/4k)
   - 保留原画质
   - 输出目录、输出文件名
5. **按需开启**:
   - TTS 配音(选择语音名)
   - 字幕烧录(字体/字号/颜色/描边/阴影/对齐)
   - 水印(文本/图片,位置/透明度等)
6. 点击「开始 AI 剪辑」,实时查看任务进度
7. 完成后查看输出文件路径;运行中可点击「取消」终止

## 6. AI 切片剪辑

长视频 → 镜头检测 → AI 精彩度评估 → 自动拆分为多条独立短视频。

### 操作步骤

1. **选择长视频文件**
2. **设置切片参数**:
   - 最小片段时长(秒)
   - 最大片段时长(秒)
   - 精彩度阈值(0~1,越高要求越严)
   - 输出片段数量(0 = 不限)
3. **设置输出参数**:
   - 分辨率、保留原画质
   - 输出目录、文件名前缀
4. 按需配置水印
5. 点击「开始 AI 切片」
6. 查看结果表格:
   - 序号、起始时间、结束时间、时长、精彩度(百分比)、输出路径
7. 运行中可「取消」任务

## 7. 文本精剪

口播/解说类视频的"点着字剪"工作台:自动转写生成句级文本轨道,点文字跳画面、选中删句、对话式改片,导出成片与原素材互不影响。

### 前置条件

- 首次使用需加载/下载本地 Whisper 语音识别模型(与「字幕提取」的语音转写共用缓存,首次下载后离线可用)
- 无需配置 LLM;若要使用「对话式改片」需在系统设置配置 LLM

### 操作步骤

1. 侧边栏进入「文本精剪」,点击「选择口播视频」
2. 等待自动转写完成(首次需加载/下载 Whisper 模型,请耐心等待)
3. **文本面板**与预览双向联动:
   - 点击任意句子 → 预览跳到该句;播放时对应句子自动高亮
   - 悬停句子点 ✕ → 删除该句(划线灰显,可撤销)
4. 一键操作:
   - **清理口头禅**:剪掉"嗯/啊/然后/就是/那个"独立成句的片段
   - **压缩停顿**:段间静音超 0.8 秒自动压到 0.2 秒
   - **撤销/重做**:最多 20 步
5. **💬 对话式改片**(需配置 LLM):输入"删掉开头的废话""把第 2 句静音"等指令 → AI 生成可勾选的编辑计划(显示操作/区间/理由)→ 确认应用
6. **导出成片**:选择输出目录 →「按时间线导出」→ 自动进行一致性校验(实际时长 vs 剪辑计划)

### 使用提示

- 所有编辑均为**非破坏性**:原素材只读,可随时"还原到原始"
- 导出时长与编辑计划偏差超过 0.5 秒时,界面会给出⚠提示
- 预览使用原片直接播放,超长视频建议耐心等待seek(低清代理预览在后续版本提供)

## 8. 影视解说克隆

### 操作步骤

1. **选择参考视频**(用于提取镜头节奏)
2. 点击「预览节奏」查看:
   - 镜头数
   - 平均时长
   - 总时长
   - 剪辑点列表
3. **输入解说文案**(用于配音与字幕;启用 TTS 时必填)
4. **添加素材文件夹**:单选,作为画面来源
5. **设置输出参数**:分辨率、保留原画质、输出目录、文件名
6. **按需开启**:TTS 配音、字幕、水印
7. 点击「开始克隆」,实时查看进度
8. 完成后查看输出路径

**提示**:节奏预览可单独执行,不依赖素材;但完整克隆需三者齐备(参考视频 + 文案 + 素材)。

## 9. 语音克隆

基于 GPT-SoVITS 的音色克隆与合成。

### 前置条件 / 连接方式

有两种方式接入 GPT-SoVITS,**二选一**即可:

- **本地模式(默认)**:需自行安装 GPT-SoVITS(Python 3.10+,应用不内置),并在页面填写**安装路径**与端口。应用自动在本机启动 `api_v2.py`。
- **远程模式**:如 GPT-SoVITS 已跑在一台服务器/另一台电脑上,只需在「服务地址」填写其 **IP 或域名**,并填写端口。应用会直接连接远端,**无需本机安装**,也不在本机启进程;「启动服务」仅做健康检查连接远端。

> 提示:服务地址留空即为本地模式(127.0.0.1);填写远程地址则连接云端。

### 操作步骤

1. **连接/启动服务**:
   - 本地模式:填写 GPT-SoVITS 安装路径
   - 远程模式:填写「服务地址」(IP/域名),安装路径可不填
   - 填写端口(默认 9880)
   - 点击「启动服务」,状态灯变绿表示就绪
   - 可随时点击「停止服务」(远程模式仅断开连接,不影响远端)或「刷新状态」

2. **克隆新音色**:
   - 点击「+ 克隆新音色」
   - 选择**样本音频**(建议 5~30 秒,wav 格式)
   - 填写**音色名称**(用于后续选择)
   - 填写**参考文本**(样本对应的文字)
   - 选择**语言**(zh / en / jp / kr / auto)
   - 提交后等待训练完成

3. **合成语音**:
   - 在音色库中选择目标音色(可删除)
   - 输入待合成文本
   - 选择输出目录、文件名
   - 调整语速(-100~100)
   - 按需勾选「同时生成 SRT 字幕」
   - 点击「开始合成」,查看音频/字幕路径

**输出格式**:wav(GPT-SoVITS 正常合成)

**Edge-TTS 自动降级**:当 GPT-SoVITS 服务未就绪或合成失败时,系统会自动降级到 Edge-TTS:
- 根据音色语言(zh/en/jp/kr)映射到对应的 Edge-TTS 默认音色
- 输出格式为 mp3(Edge-TTS 原生格式)
- 合成结果中会标注 `fallback=true` 及降级原因,便于诊断
- 无需用户干预,保证合成流程不中断

2. **填写发布信息**:

   - 填写标题、描述、话题

6. **队列管理**:

## 11. 自动流水线(v2.1)

把全自动步骤串成链一键执行:**素材分割 → 随机混剪 → 自动发布**。任一步失败即停,后续步骤标记 blocked;人工步骤(文本精修)不进链,完成后在任务中心取产物再手动精修。

**新建管线**:
1. 进入「自动流水线」页 → 「新建流水线」
2. 输入名称,点「+ 素材分割 / + 随机混剪 / + 自动发布」追加步骤
3. 每步参数以 JSON 编辑(常用默认值已预填;发布步骤的 `videoPath` 留空且 `usePrevArtifact: true` 时自动接上一步产物)
4. 步骤可「↑↓」调序、「✕」删除
5. 「保存」落库(保存时逐字段校验)

**运行**:
- 列表卡片点「运行」,管线作为一个任务进入任务中心,整体进度 = 完成步数/总步数
- 失败即停:失败步标 failed、其后全部 blocked,错误信息进任务中心
- 发布步骤入队后由发布串行链接管,进度在任务中心单独呈现

**定时执行**:
- 卡片「设置定时」:每天 / 每周(选星期)/ 一次,时间 HH:mm
- 勾选「启用定时」保存后,应用运行期间到点自动触发(约每分钟轮询一次)
- 最近一次运行状态在卡片「最近」一览

**删除**:卡片「删除」即从列表移除(历史运行状态一并清除)。

### 10.1 AI 语义识别模型(中英 CN-CLIP)

AI 剪辑、影视解说克隆等"文案 → 画面"语义匹配基于 CN-CLIP 双塔 ONNX 模型。首次使用需下载约 760MB 权重(图像塔 + 文本塔 + 中文词表)到本机,之后离线可用。

**查看引擎状态**:
- **引擎状态**:显示「真实 ONNX 引擎」表示模型已下载且推理引擎可用;
  显示「Mock(降级,未加载真实模型)」表示尚未下载模型或推理引擎不可用,此时语义匹配精度有限。
- **权重就绪**:三点模型文件均存在时为「已就绪」。

**下载 / 补齐模型**:
1. 若「权重就绪」为「未就绪」,点击「下载模型」按钮。
2. 进度条显示当前文件与百分比,依次下载图像塔 / 文本塔 / 词表。
3. 下载完成后「权重就绪」变为「已就绪」。若引擎自动刷新成功,「引擎状态」切换为「真实 ONNX 引擎」。

**自定义模型目录**:
1. 在「模型目录」输入框直接粘贴路径,或点击「选择目录」打开系统选择器(建议选到空间充足的磁盘,如 `D:\CLIP-Models`)。
2. 点击「应用」保存并切换目录;下方会显示「当前:xx」确认生效。
3. 切换目录后按需重新点击「下载模型」,把权重下载到新目录。
4. 清空输入框后点「应用」,可恢复默认目录(`C:\Users\<用户名>\AppData\Roaming\jack-video-fusion\models`)。

> 提示:切换到含已下载模型的自定义目录时,无需重新下载;「权重就绪」会直接显示「已就绪」。

## 13. 常见问题

### Q1:点击按钮没反应/报错?

- **Electron 桌面应用**:请检查系统设置是否完整配置(LLM、输出目录等)
- **浏览器 dev 环境**:`npm run dev` 启动的纯浏览器环境下,IPC 不可用,部分按钮会提示"IPC 不可用:当前为浏览器 dev 环境"。这是预期行为,完整功能请用 `npm run dev:electron` 启动 Electron 应用

### Q2:AI 剪辑顶部显示黄色警告?

LLM 未配置。请前往「系统设置 → LLM 配置」填写:
- Provider(openai/qwen/ollama/custom)
- 接口地址
- API Key(ollama 可留空)
- 模型名

### Q3:微软 TTS 合成失败?

- 检查网络连接(需访问微软服务)
- 文本不要超过 5 万字(超限会自动截断)
- 重新选择音色再试

### Q4:语音克隆无法启动?

- 确认已安装 GPT-SoVITS 并填写正确路径
- 确认端口未被占用(默认 9880)
- 点击「刷新状态」查看服务实际状态
- 样本音频建议 5~30 秒,过长会降低克隆质量

### Q5:字幕提取显示"跳过"?

说明该视频无内嵌字幕轨道。在「字幕提取」时可按需在下拉框选择兜底识别方式:
- **OCR 识别画面文字**:适合画面中**烧录/硬编码**的文字,本地识别生成 SRT(首次需联网下载语言包,之后离线可用)。识别精度受画面清晰度、字体与字幕样式影响。
- **语音识别人声**:适合**解说、旁白、对白**等口播内容,基于 Whisper 本地模型识别(首次需联网下载语音模型,之后离线可用)。模型缓存于本机,生成速度与模型规格(base/small/medium)有关。

### Q6:自动发布提示账号过期?

- 平台 Cookie 有有效期,过期需重新扫码登录
- 建议每次使用前点击「检测状态」确认
- 避免频繁发布,遵守平台频率限制

### Q7:任务卡在排队中?

- 系统设置中「任务并发数」控制同时运行的任务数
- 默认建议 1,避免 ffmpeg 资源争抢
- 可在任务面板取消排队中的任务

### Q8:如何查看运行日志?

侧边栏底部有日志面板,支持按级别(info/warn/error/debug)和模块过滤,可导出日志文件。

### Q9:数据存储在哪里?

所有配置、任务记录与本地模型存储在系统数据目录:
- Windows: `C:\Users\<用户名>\AppData\Roaming\jack-video-fusion\`
  - `config\` - 全局配置、参数模板
  - `task-queue\` - 任务记录
  - `task-checkpoints\` - 任务断点缓存
  - `projects\` - 工程文件
  - `voice-library\` - 语音克隆音色库
  - `models\` - 本地模型
    - `models\asr\` - Whisper 语音识别模型
    - `models\` - CN-CLIP 语义识别模型(默认目录;可在「系统设置」中自定义)
  - `logs\` - 运行日志

> 提示:CN-CLIP 模型下载目录可在「系统设置 → AI 语义识别模型」中自定义到任意磁盘位置。

### Q10:如何升级到新版本?

- **安装包用户(推荐)**:在「系统设置 → 关于」点「检查更新」,发现新版本后点「下载更新」,完成后点「重启安装」即可自动升级(配置与数据保留)。
- **手动更新**:下载新 exe 直接覆盖安装,配置和数据保留。
- **开发者**:`git pull && npm install && npm run build:electron`

### Q11:混剪任务暂停后能恢复吗?

可以。v1.2.1 起支持断点续渲染:
- 暂停时,系统会保存当前步骤的 checkpoint(含中间产物路径)
- 恢复时自动校验中间文件存在性,跳过已完成的步骤(选取/拼接/缩放/水印/字幕)
- 若 checkpoint 文件丢失或中间产物被删除,会自动从头开始
- 模式二(音频匹配)支持文件夹级续渲染,从最近完成的文件夹继续

### Q12:CLIP 画面匹配用的是真实模型吗?

取决于模型是否已下载以及推理引擎是否可用:
- **真实 ONNX 推理**:当 `onnxruntime-node` 可用,且模型目录下的双塔与词表文件齐全(`vit-b-16.img.fp32.onnx` 图像塔、`vit-b-16.txt.fp32.onnx` 文本塔、`vocab.txt`)时,使用真实 CN-CLIP 推理。
- **Mock 降级**:任一条件不满足时降级到确定性伪向量引擎(同一输入永远产出同一向量,可跑通流程但匹配精度有限)。
- 首次使用请到「系统设置 → AI 语义识别模型」点击「下载模型」下载权重(约 760MB);也可自定义模型目录存放。
- 日志会标注当前引擎类型(`[CLIP] 已启用真实 ONNX 推理引擎` 或 `[CLIP] 降级到 Mock 引擎`)。

### Q13:语音识别(ASR)第一次用很慢/要联网?

首次使用「语音识别人声」时需从网络下载 Whisper 语音模型到本机(`userData\models\asr\`),下载时间取决于网络与所选模型规格;
后续使用走本地缓存,离线可用。较大规格(base/small/medium)识别更准但更慢、占空间更大,默认 base 兼顾速度与精度。

### Q14:自动更新检查失败 / 提示错误?

- **开发环境(`npm run dev:electron`)下自动更新不可用,显示「开发环境不可用」属预期行为**;请使用打包安装版测试。
- 打包版运行后,在「系统设置 → 关于」点击「检查更新」会连接发布源(**GitHub Releases**)查询最新版本;请确保网络可访问 GitHub。
- 若已是最新版本显示「已是最新版本」;有新版则显示「下载更新」→ 下载后可「重启安装」。
- 若仓库尚未发布与你当前版本匹配的 release(如只发布了旧版本),会提示未找到更新或检查失败。
