## 1. 快速开始

### 1.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 64 位及以上 |
| Node.js | 24.x(开发者) |
| 磁盘空间 | ≥ 2 GB(含 ffmpeg、onnxruntime 等依赖) |
| 内存 | ≥ 8 GB(AI 剪辑/语音克隆建议 16 GB) |
| 网络 | 微软 TTS、LLM、自动发布需联网;本地剪辑离线可用 |

### 1.2 安装与启动

**普通用户(安装包)**:
1. 双击 `AI智剪工坊-1.2.0-x64.exe`
2. 按向导完成安装,勾选"创建桌面快捷方式"
3. 从开始菜单或桌面图标启动

**开发者(源码运行)**:
```bash
# 安装依赖
npm install

# 开发模式(完整 Electron 应用)
npm run dev:electron

# 生产构建
npm run build:electron

# 打包 Windows 安装包
npm run package:win
```

### 1.3 首次启动

首次启动会显示**免责声明**页,阅读后点击「我已阅读并同意」进入主界面。免责声明要点:
- 用户需自行保证素材版权合法
- 遵循微软 TTS 开源协议,不剥离/单独售卖语音能力
- 所有素材处理在本地完成,不上传云端
- 自动发布需遵守各平台规则,违规后果自负

- **侧边栏(左侧 200px)**:8 个功能模块入口、任务队列、本地模式状态指示

### 功能模块速查

| 模块 | 功能 | 是否需联网 |
|------|------|-----------|

| 自动发布 | 多平台批量发布 | 是 |

## 3. 素材处理

进入「素材处理」模块,顶部有 4 个 Tab:素材分割、文本分割、微软TTS、字幕提取。

### 3.1 素材分割

按固定时长将单个视频分割为多个片段。

**操作步骤**:
1. 点击「选择」或拖拽视频文件到输入框(支持 mp4/mov/avi/mkv/flv)
2. 选择输出目录
3. 设置**单片段时长**(秒,默认 10)
4. 设置**命名规则模板**(默认 `{name}_{index}`)
5. 按需勾选「保留原画质」「去原声」
6. 点击「开始分割」,实时查看进度
7. 完成后查看分割结果列表

**示例**:输入 `解说.mp4`,时长 60 秒,设单片段 10 秒,输出 6 个文件:`解说_1.mp4` ~ `解说_6.mp4`。

### 3.2 文本分割

按字数切分长文本,批量导出为 TXT。

**操作步骤**:
1. 点击「导入 TXT」或直接粘贴文本到文本框
2. 设置**单条最大字数**(默认 100)
3. 按需勾选「保留标点」「自动分段」
4. 点击「开始分割」
5. 查看分割结果(每条片段 + 字数)
6. 点击「导出 TXT」下载合并文件

### 3.3 微软 TTS

基于微软 Edge TTS 合成中文语音,可同步生成 SRT 字幕。

**操作步骤**:
1. 选择**音色**(6 种内置:晓晓/云健等,男女声各 3 种)
2. 拖动滑块调整**语速**(-100~100)、**音量**(0~100)、**音调**(-100~100)
3. 选择输出目录
4. 按需勾选「同时生成 SRT 字幕」
5. 导入 TXT 或粘贴文本(查看字符计数,**上限 5 万字**)
6. 点击「开始合成」,查看音频/字幕输出路径

### 3.4 字幕提取

批量提取视频内嵌字幕流,生成 SRT 文件。

**操作步骤**:
1. 点击「批量选择」添加多个视频文件
2. 在文件列表中可移除单个文件
3. 选择输出目录
4. 点击「开始提取」
5. 查看每个文件状态:
   - ✓ 成功:已提取字幕
   - ✕ 失败:提取出错
   - — 跳过:无内嵌字幕流
6. 查看顶部「成功/失败/共」汇总

## 4. 视频混剪

两种混剪模式,通过顶部 Tab 切换。

### 4.1 随机素材混剪

从多文件夹随机抽取片段拼接成新视频。

**操作步骤**:
1. 点击「+ 添加文件夹」添加 1 个或多个素材文件夹
2. 设置输出参数(分辨率、目录、文件名)
3. 按需配置 TTS 配音、字幕、水印
4. 点击「开始混剪」

### 4.2 文件夹音频匹配

每个文件夹用其对应的音频配视频合成。

**操作步骤**:
1. 添加文件夹(每个文件夹应含视频和对应音频)
2. 设置输出参数
3. 按需配置水印
4. 点击「开始匹配混剪」

## 5. AI 剪辑

输入解说文案,LLM 抽取关键词 + CLIP 语义匹配画面,自动切镜合成成片。

### 前置条件

- **必须配置 LLM**(系统设置 → LLM 配置):
  - Provider:openai / qwen / ollama / custom
  - 接口地址、API Key、模型名
  - ollama 允许空 API Key
- 若未配置,页面顶部显示黄色警告,无法开始

### 操作步骤

1. **输入解说文案**:按句号或换行分段,每段匹配一个画面
2. 可点击「预览关键词」验证 LLM 抽取效果
3. **添加素材文件夹**:点击「+ 添加文件夹」,单选一个文件夹作为画面来源(可刷新素材数)
4. **设置输出参数**:
   - 分辨率(720p/1080p/4k)
   - 保留原画质
   - 输出目录、输出文件名
5. **按需开启**:
   - TTS 配音(选择语音名)
   - 字幕烧录(字体/字号/颜色/描边/阴影/对齐)
   - 水印(文本/图片,位置/透明度等)
6. 点击「开始 AI 剪辑」,实时查看任务进度
7. 完成后查看输出文件路径;运行中可点击「取消」终止

## 6. AI 切片剪辑

长视频 → 镜头检测 → AI 精彩度评估 → 自动拆分为多条独立短视频。

### 操作步骤

1. **选择长视频文件**
2. **设置切片参数**:
   - 最小片段时长(秒)
   - 最大片段时长(秒)
   - 精彩度阈值(0~1,越高要求越严)
   - 输出片段数量(0 = 不限)
3. **设置输出参数**:
   - 分辨率、保留原画质
   - 输出目录、文件名前缀
4. 按需配置水印
5. 点击「开始 AI 切片」
6. 查看结果表格:
   - 序号、起始时间、结束时间、时长、精彩度(百分比)、输出路径
7. 运行中可「取消」任务

## 7. 影视解说克隆

复刻参考解说视频的镜头节奏,用自有素材替换画面,配合自定义 TTS 配音与字幕,生成全新原创解说视频。

### 操作步骤

1. **选择参考视频**(用于提取镜头节奏)
2. 点击「预览节奏」查看:
   - 镜头数
   - 平均时长
   - 总时长
   - 剪辑点列表
3. **输入解说文案**(用于配音与字幕;启用 TTS 时必填)
4. **添加素材文件夹**:单选,作为画面来源
5. **设置输出参数**:分辨率、保留原画质、输出目录、文件名
6. **按需开启**:TTS 配音、字幕、水印
7. 点击「开始克隆」,实时查看进度
8. 完成后查看输出路径

**提示**:节奏预览可单独执行,不依赖素材;但完整克隆需三者齐备(参考视频 + 文案 + 素材)。

## 8. 语音克隆

基于 GPT-SoVITS 的音色克隆与合成。

### 前置条件

- 需自行安装 GPT-SoVITS(本应用不内置)
- 首次使用需在页面配置 GPT-SoVITS 安装路径与端口

### 操作步骤

1. **启动服务**:
   - 填写 GPT-SoVITS 安装路径
   - 填写端口(默认 9880)
   - 点击「启动服务」,状态灯变绿表示就绪
   - 可随时点击「停止服务」或「刷新状态」

2. **克隆新音色**:
   - 点击「+ 克隆新音色」
   - 选择**样本音频**(建议 5~30 秒,wav 格式)
   - 填写**音色名称**(用于后续选择)
   - 填写**参考文本**(样本对应的文字)
   - 选择**语言**(zh / en / jp / kr / auto)
   - 提交后等待训练完成

3. **合成语音**:
   - 在音色库中选择目标音色(可删除)
   - 输入待合成文本
   - 选择输出目录、文件名
   - 调整语速(-100~100)
   - 按需勾选「同时生成 SRT 字幕」
   - 点击「开始合成」,查看音频/字幕路径

**输出格式**:wav

## 9. 自动发布

多平台(抖音/快手/小红书/B站)账号管理与视频批量/定时发布。

> ⚠️ **合规提示**:自动化发布存在账号风险,因违规操作产生的后果由用户自行承担。

### 操作步骤

1. **账号登录**:
   - 在「平台账号」区对每个平台操作:
   - 点击「扫码登录」弹出二维码
   - 用对应平台 App 扫码完成登录
   - 可点击「检测状态」验证登录是否有效
   - 状态:已登录 / 已过期 / 未登录

2. **填写发布信息**:
   - 选择视频文件
   - 填写标题、描述、话题
   - 选择封面图片(可选)

3. **设置发布时间**:
   - 留空 = 立即发布
   - 选择时间 = 定时发布(部分平台不支持)

4. **选择发布平台**:勾选一个或多个

5. **加入队列**:
   - 点击「添加到发布队列」
   - 单平台用 publish,多平台自动用 batchPublish

6. **队列管理**:
   - 查看任务实时进度
   - 可取消未完成任务
   - 可清理已完成任务

## 10. 系统设置

管理全局配置,影响所有模块的默认行为。

### 配置项

| 分类 | 配置项 | 说明 |
|------|--------|------|
| 通用 | 默认分辨率 | 720p / 1080p / 4k |
| 通用 | 保留原画质 | 复选框 |
| 通用 | 默认导出目录 | 所有模块的默认输出路径 |
| 水印 | 类型/内容/位置/透明度/字号 | 影响所有启用水印的模块 |
| 字幕 | 字体/字号/颜色/描边/阴影/对齐 | 影响所有启用字幕的模块 |
| 任务 | 任务并发数 | 1~4,建议 1(避免资源争抢) |
| LLM | Provider | openai / qwen / ollama / custom |
| LLM | 接口地址 | API endpoint |
| LLM | API Key | password 字段隐藏 |
| LLM | 模型 | 如 gpt-4、qwen-plus 等 |

### 操作

- 进入页面自动加载当前配置
- 修改后点击「保存设置」生效
- 点击「恢复默认」重置所有配置
- 底部显示版本号(v1.2.0)与免责声明

## 11. 常见问题

### Q1:点击按钮没反应/报错?

- **Electron 桌面应用**:请检查系统设置是否完整配置(LLM、输出目录等)
- **浏览器 dev 环境**:`npm run dev` 启动的纯浏览器环境下,IPC 不可用,部分按钮会提示"IPC 不可用:当前为浏览器 dev 环境"。这是预期行为,完整功能请用 `npm run dev:electron` 启动 Electron 应用

### Q2:AI 剪辑顶部显示黄色警告?

LLM 未配置。请前往「系统设置 → LLM 配置」填写:
- Provider(openai/qwen/ollama/custom)
- 接口地址
- API Key(ollama 可留空)
- 模型名

### Q3:微软 TTS 合成失败?

- 检查网络连接(需访问微软服务)
- 文本不要超过 5 万字(超限会自动截断)
- 重新选择音色再试

### Q4:语音克隆无法启动?

- 确认已安装 GPT-SoVITS 并填写正确路径
- 确认端口未被占用(默认 9880)
- 点击「刷新状态」查看服务实际状态
- 样本音频建议 5~30 秒,过长会降低克隆质量

### Q5:字幕提取显示"跳过"?

该视频文件无内嵌字幕流。字幕提取只能提取已硬编码的字幕轨道,无法识别画面中的文字(OCR 不在 v1.2.0 范围)。

### Q6:自动发布提示账号过期?

- 平台 Cookie 有有效期,过期需重新扫码登录
- 建议每次使用前点击「检测状态」确认
- 避免频繁发布,遵守平台频率限制

### Q7:任务卡在排队中?

- 系统设置中「任务并发数」控制同时运行的任务数
- 默认建议 1,避免 ffmpeg 资源争抢
- 可在任务面板取消排队中的任务

### Q8:如何查看运行日志?

侧边栏底部有日志面板,支持按级别(info/warn/error/debug)和模块过滤,可导出日志文件。

### Q9:数据存储在哪里?

所有配置和任务记录存储在系统 `userData` 目录:
- Windows: `C:\Users\<用户名>\AppData\Roaming\AI智剪工坊\`
  - `config\` - 全局配置、参数模板
  - `data\` - 任务记录
  - `projects\` - 工程文件
  - `logs\` - 运行日志

### Q10:如何升级到新版本?

- 安装包用户:下载新 exe 直接覆盖安装,配置和数据保留
- 开发者:`git pull && npm install && npm run build:electron`
