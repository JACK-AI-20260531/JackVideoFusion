# PRD v1.7 — 数据飞轮与全景矩阵

> 版本:1.7.0 | 状态:开发中 | 前置:v1.5(爆款评分)、v1.6(发布闭环)
> 定位:把 v1.5→v1.6 的"评分→发布→回收"半闭环焊死为**自学习飞轮**,同时补齐矩阵发布的多平台通道与素材治理底座。

## 1. 背景与目标

v1.6 交付了发布数据回收,但仍是**手动**粘链接 + 手动采集;爆款评分权重为人工设定;矩阵发布仅支持抖音;批量混剪存在素材高频复用导致平台限流的隐患。本版本围绕四个目标:

1. **飞轮自动化**:发布成功 → 自动绑定链接 → 定时采集 → 看板呈现,全程零手工;
2. **评分自学习**:用真实播放/互动数据回归校准五维评分权重,评分从"拍脑袋"进化为"数据驱动";
3. **矩阵扩容**:新增快手/视频号/B站/小红书发布通道,消除单平台瓶颈;
4. **底座加固**:素材防撞车、品牌一致性、诊断包导出。

## 2. 用户故事

- 作为运营者,我发布成功后不用手动复制链接,系统自动记录并每天采集数据,打开看板就能看趋势。
- 作为运营者,我看板能告诉我"爆款评分高的视频实际数据是否真的好",评分权重随我的账号数据自动进化。
- 作为矩阵运营者,我把同一条视频一键发布到快手/视频号/B站/小红书,各平台规格自动适配。
- 作为批量混剪用户,系统提醒我"该素材近 3 天已在 2 条视频中使用",避免平台原创度限流。
- 作为打包版用户,遇到问题时一键导出诊断包发给开发者。

## 3. 功能需求(FR)

### FR-1 发布数据自动回收(优先级 P0)
- 发布任务成功后,若适配器返回作品页 URL,自动写入 `analytics-store` 绑定,**无需手动粘贴**;手动绑定保留作为兜底。
- 新增定时采集调度:每日凌晨(可配置)对全部已绑定链接自动 `fetchStats`,失败静默重试,连续 3 次失败标记 `stale` 并在看板提示。
- 采集窗口期(发布后 72h)内加密采集频率(每 6h),把握早期流量曲线。

### FR-2 数据看板(优先级 P0)
- 发布页新增「数据看板」标签页:
  - 汇总卡片:近 7/30 天总播放、总互动、发布条数、平均爆款分;
  - 单条漏斗:曝光→播放→完播→点赞→评论(数据缺失项显示"—"不显示 0);
  - 趋势图:纯 SVG 折线图(无新依赖),可切换 播放/互动 两指标。
- 全部渲染层计算,IPC 只吐原始时间线,禁止在看板里做 I/O。

### FR-3 评分权重自学习(优先级 P0,护城河)
- 纯函数 `calibrateWeights(samples)`:输入 `{score5维, 实际互动率}` 样本集(≥20 条启用,不足回退默认权重),对各维度与互动率做皮尔逊相关系数 → 归一化为新权重,与默认权重按 `0.3 新 + 0.7 旧` 平滑混合,防止单次过拟合。
- 校准结果持久化到全局配置 `viralityWeights`,评分链路自动读取;设置页展示当前权重与"已学习样本数",可一键重置。
- 单测覆盖:样本不足回退、相关系数符号正确、权重归一化(和为 1)、平滑混合。

### FR-4 多平台发布适配器(优先级 P1)
- 新增适配器:快手、视频号(微信)、B站、小红书;沿用 v1.6 发布适配器接口,每个适配器声明:
  - 能力位:`{autoPublish: boolean, needQrcode: boolean}`(接口不稳定时降级为半自动:生成发布物料包+打开平台页);
  - 规格约束:标题长度上限、标签数上限、封面比例(9:16/16:9/3:4),批量发布前统一预校验,不合规项阻断并提示。
- 平台枚举与图标同步到发布表单、CSV 导入(平台名中英文均可)、定时任务。

### FR-5 素材库治理(优先级 P1)
- 使用计数:每次混剪/AI 混剪成功产出,为所用素材累加使用次数与最近使用时间(持久化 `usage.json`)。
- 防撞车:选材时若素材在「间隔窗口(默认 7 天,可配)」内已被使用,给出黄色警告并支持"跳过已用素材"开关。
- 感知哈希去重:dHash 64 位,汉明距离 ≤8 视为重复;入库时计算存储,重复项在素材列表标灰。
- 素材标签与搜索:手动打标签 + 按标签/使用次数/时长筛选。

### FR-6 热点选题管线(优先级 P1,v2.0 前奏)
- 聚合热榜(抖音热点/百度热搜)→ 去重 → LLM 结合用户素材库生成 5 条选题建议(标题+切入角度+适配素材标签)。
- 选题一键生成脚本(沿用 llm provider,温度 ≤0.3,JSON 容错解析),脚本存入素材库文本片段,为 v2.0「文本即时间线」铺垫。
- 热榜接口全部容错:任一源失败不影响整体,全失败时显示"热点服务暂不可用"。

### FR-7 品牌套件(优先级 P2)
- 全局品牌配置:水印图(位置/透明度)、片头片尾片段、统一滤镜(亮度/对比度/饱和度微调)、目标规格(9:16/16:9)。
- 混剪导出时可选"应用品牌套件",ffmpeg filter 链一次合成,不二次转码。

### FR-8 稳健性收尾(优先级 P1)
- 一键导出诊断包:日志 + 配置(脱敏,去除密钥)+ 版本/系统信息 → zip 到用户选择目录。
- 账号健康度:发布适配器检测 cookie/凭据过期,提前 3 天在发布页黄条预警,避免批量任务中途失败。

## 4. 技术方案要点

- 纯函数与编排分离:`calibrateWeights`/`dHash`/`hammingDistance`/`aggregateDashboard` 等全部为不依赖 electron 的纯函数,`__tests__` 全覆盖;
- 定时采集复用 `schedule-store` 状态机思路,新增 `analytics-scheduler`(纯编排 + 注入 timer);
- 多平台适配器沿用 v1.6 适配器接口,新增能力位字段,旧抖音适配器不受影响;
- 看板 SVG 图表自绘,不引入图表库(保持零新增运行时依赖);
- 热榜抓取带 Chrome UA + 超时 5s + 单源容错(沿用 model-downloader 的 UA 经验)。

## 5. 里程碑

| 里程碑 | 内容 | 说明 |
|--------|------|------|
| M1 | FR-1/2/3 数据飞轮 | 自动回收 + 看板 + 权重自学习 |
| M2 | FR-4 多平台适配器 | 快手/视频号/B站/小红书 |
| M3 | FR-5 素材库治理 | 使用计数 + 防撞车 + 去重 |
| M4 | FR-6/7 热点 + 品牌套件 | 选题管线 + 品牌一致性 |
| M5 | FR-8 稳健性 + 发版 | 诊断包/健康度/版本号/打包/Release |

## 6. 成功指标

- 发布后数据零手动操作率 ≥90%(自动绑定成功率);
- 连续 30 天采集后,校准权重与默认权重的互动率相关性提升(自学习生效);
- 4 新平台完成发布链路(至少半自动模式);
- 素材复用警告触达率 100%,重复素材检出可用。

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 各平台发布接口逆向不稳定 | 能力位降级为半自动物料包模式,不阻塞主流程 |
| 热榜接口无官方开放 | 多源聚合 + 全容错,失败可降级为纯 LLM 选题 |
| 自学习样本不足 | 样本 <20 回退默认权重,平滑混合防过拟合 |
| 版本膨胀 | 高风险项(D 热点)允许滑入 v1.8,M1/M2/M3 为必达 |
