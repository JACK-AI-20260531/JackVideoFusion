## 1. 开篇:一条视频是怎么生产出来的

不管做什么内容,生产链路基本一致,**先备料 → 再拼接/剪辑 → 加声音字幕 → 最后发布**:

```
【备料】     【加工/创意】      【包装】         【发布】
素材分割  →  视频混剪        →  TTS配音      →  自动发布
AI切片      AI剪辑            字幕/水印         导出目录
语音克隆    影视解说克隆
```

管线就是把这个链路拆成**可照做的固定顺序**。建议按"**先准备 → 后生产 → 再发布**"的原则,不要跳步。

## 2. 准备工作(所有流程通用)

每个管线开工前,先把公共环境配好,**只做一次**:

### 2.1 全局设置(系统设置)
1. 打开「系统设置」。
2. 设置**默认导出目录**(所有模块的输出默认放这里)。
3. 设置**默认分辨率**(720p/1080p/4k)与「保留原画质」。
4. 设置**任务并发数**(默认 1,机器强、磁盘快可适当加到 2)。
5. 点「保存设置」。

### 2.2 AI 能力(按需)
| 能力 | 用途 | 用到的流程 | 配置位置 |
|------|------|-----------|---------|
| **LLM 大模型** | 文案→关键词抽取 | 管线 B/C/D(AI 剪辑、AI 切片、解说克隆) | 系统设置 → LLM 大模型 |
| **CN-CLIP 模型** | 文案→画面语义匹配 | 管线 B/D | 系统设置 → AI 语义识别模型(先下载模型,可自定义目录) |
| **GPT-SoVITS** | 定制音色克隆 | 管线 B/D | 语音克隆页(需自行安装) |
| **微软 TTS** | 普通配音 | 管线 A/B/D | 各功能页直接选音色 |

> 提示:LLM 与 CLIP 模型选填,不用 AI 语义功能的纯混剪流程(C 线 A 后半段)可不配,流程更简单。

## 3. 管线 A:素材库批量混剪

**适用**:有一批现成素材片段,想自动抓取、拼接、配乐/配音,批量出多条成品短视频。

**按顺序依次执行**:

1. **素材分割**(若原始素材是整段长视频)
   - 目的:把长视频切成可复用的短片段。
   - 素材处理 → 素材分割 → 选视频 → 设单片段时长(建议 5~15 秒)→ 开始分割。
   - 产出:一堆 `xxx_1.mp4`、`xxx_2.mp4` 片段。

2. **文本分割**(可选,若文案需要分条)
   - 长文案按字数切分,为后续每段配一条说明/字幕做准备。

3. **整理素材文件夹**
   - 把切好的片段按主题/风格放入多个文件夹(一个文件夹 = 一类题材)。
   - 若做"音频对视频"混剪,每个文件夹内放对应视频 + 对应音频。

4. **视频混剪**
   - 视频混剪 → 随机素材混剪(或多个文件夹)。
   - 添加文件夹 → 设每文件夹抽取条数/总时长/单片段时长/转场 → 设输出参数 → 按需加配音/字幕/水印 → 开始混剪。
   - 产出:多条拼接后的成品视频。

5. **批量配音/加字幕**(可选)
   - 微软 TTS 生成配音 → 生成 SRT;或直接在混剪输出时勾选字幕。

6. **导出取用**
   - 从输出目录取成品;可直接作为发布素材。

**此流程的开关**:只做"拼接+配乐"可全程离线;用 TTS 配音需联网。

## 4. 管线 B:解说 / 口播视频生产

**适用**:有一条**解说文案**,希望机器把内容"念出来 + 画面自动配上 + 裁剪成片"。

**按顺序依次执行**:

1. **准备素材文件夹(画面来源)**
   - 用「素材分割」或直接准备一个装满画面的文件夹(风景/空镜/对应场景)。
   - 不要一个文件夹塞几十个无关文件,尽量按解说主题归档。

2. **配置 LLM(若用 AI 剪辑)**
   - 系统设置 → LLM:填 Provider/接口地址/API Key/模型名。
   - 不配则不可用,页面顶部会黄色警告。

3. **下载 CN-CLIP 模型(若用语义匹配找画面)**
   - 系统设置 → AI 语义识别模型 → 下载模型(首次约 760MB)。
   - 建议在系统设置里自定义模型目录到空间充足的盘。

4. **准备音色(若用专属配音)**
   - 语音克隆页:启动 GPT-SoVITS → 克隆新音色(样本 5~30 秒 wav + 参考文本)→ 得到音色。
   - 不用专属音色可直接用微软 TTS 默认音色。

5. **写解说文案并分段**
   - 按句号或换行分段,每段对应用一个画面(利于逐段匹配)。

6. **AI 剪辑(核心生产)**
   - AI 剪辑 → 粘贴文案 → 预览关键词 → 添加素材文件夹 → 设输出参数 → 勾选 TTS 配音/字幕/水印 → 开始 AI 剪辑。
   - 产出:配音+画面+字幕已合成的一条成品视频。

7. **后期/发布**
   - 预览成品,必要时用导出/发布。

**要点**:LLM 决定"每段说了什么能匹配什么",CLIP 决定"从素材里挑哪段画面",素材文件夹质量直接决定成片质量。

## 5. 管线 C:长视频二次创作

**适用**:手里是**一条很长的视频**(直播回放/长横屏/纪录片),想自动切成多条独立短视频再精选/发布。

**按顺序依次执行**:

1. **AI 切片切割(切分)**
   - AI 切片剪辑 → 选择长视频 → 设最小/最大片段时长、精彩度阈值、输出数量 → 开始 AI 切片。
   - 产出:多条带时间点与精彩度评分的子视频。

2. **精选(人工决策)**
   - 看结果表格里的**精彩度百分比**,挑出高分片段;低分的可丢弃。

3. **二次加工(可选)**
   - 对精选片段用「随机混剪」或「素材分割+混剪」合并、加转场,或到「AI 剪辑」配上解说/TTS。

4. **发布**
   - 把成片交给自动发布批量投递。

**此流程全程本地,无需 LLM/CLIP**;只有 AI 切片内部的"精彩度评估"与画面有关,但仍离线。

## 6. 管线 D:影视解说克隆

**适用**:有一部参考解说视频,**想保留它的镜头节奏**,换成你自己的文案/画面/声音,做出"新原创新解说"。

**按顺序依次执行**:

1. **选参考视频(节奏模板)**
   - 影视解说克隆 → 选择参考视频 → 「预览节奏」看镜头数/平均时长/剪辑点,确认节奏可接受。

2. **写解说文案**(匹配节奏长度)
   - 文案总时长应与参考视频节奏匹配;启用 TTS 时必填。

3. **准备素材文件夹(画面来源)**
   - 单文件夹作为画面替换来源;质量越高越好。

4. **准备音色(可选)**
   - 语音克隆出专属音色,或直接用微软 TTS。

5. **开始克隆**
   - 影视解说克隆 → 参考视频 + 文案 + 素材文件夹 + 输出参数 + 配音/字幕/水印 → 开始克隆。
   - 产出:以参考节奏为骨架、内容全新的一条视频。

6. **发布**
   - 交给自动发布或手动导出。

**依赖**:节奏预览可单独做;完整克隆需"参考视频 + 文案 + 素材"三样齐备。文案匹配画面需 LLM/CLIP(可选,可只用纯节奏+素材轮播)。

---

## 7. 管线 E:全自动批量发布

**适用**:把一批做好的成品视频,**自动/定时**批量发到抖音/快手/小红书/B站/微信视频号。

**按顺序依次执行**:

1. **准备成品视频 + 文案**
   - 收集各管线产出的成品视频;为每条写标题/描述/话题/封面。

2. **账号登录(每个平台一次)**
   - 自动发布 → 各平台「扫码登录」→「检测状态」确认已登录。

3. **组装发布任务**
   - 添加视频(可多选)→ 填标题/描述/话题/封面 → 设发布时间(留空=立即)→ 勾选平台。

4. **加入队列并管理**
   - 「添加到发布队列」→ 查看进度 → 可按需暂停/取消/清理。

5. **合规注意**
   - 遵守各平台规则与发布频率,避免封号。

## 8. 管线 F:自动流水线(分割 → 混剪 → 发布一键跑,可选)

**适用**:重复性的"分割 → 混剪 → 发布"固定流程,想存成模板、一键或定时自动跑(v2.1)。

1. **编排**:自动流水线页 → 新建 → 依次「+ 素材分割 / + 随机混剪 / + 自动发布」,每步参数 JSON 可改(默认值已预填)。
2. **保存**:保存时逐字段校验,通过后落库本地。
3. **一键跑**:列表点「运行」,整条链作为一个任务进任务中心;失败即停,后续标 blocked。
4. **定时跑**:设置每天/每周/一次的触发时间并启用,应用运行期间到点自动执行。
5. **人工衔接**:链完成后,产物在任务中心;如需精修,取产物进「文本精剪」,再手动/批量发布。

> 与管线 A→E 的区别:管线 F 把三段固定流程"存起来复用",适合日更账号的标准化生产。

## 9. 何时用哪个方案(决策表)

| 你的起点 | 你想得到 | 走哪条管线 |
|---------|---------|-----------|
| 一推素材片段 | 批量成品短视频 | **A 素材库批量混剪** |
| 一条解说文案 | 有配音有画面的成片 | **B 解说/口播视频生产** |
| 一条长视频 | 多条精彩短视频 | **C 长视频二次创作** |
| 一条参考解说视频 | 同节奏的全新原创解说 | **D 影视解说克隆** |
| 一堆成品视频 | 自动发到各平台 | **E 全自动批量发布** |
| 固定的重复生产流程 | 一键/定时自动跑 | **F 自动流水线(第 8 节)** |
| 一条口播视频 | 删掉废话/口头禅的精修成片 | **文本精剪(第 11 节)** |

**快速的子选择**:
- 只想自动拼接+配乐 → 管线 A(纯本地)。
- 想要"文案驱动、自动挑画面" → 管线 B → 需 LLM + CLIP。
- 想要"保留参考节奏" → 管线 D。
- 想把长视频拆短 → 管线 C。

## 10. 常见组合与示例

### 示例 1:"一天 100 条带货短视频"(A → E)
1. 素材分割:把 10 盘产品长视频切成 1000 个短片段。
2. 视频混剪:每文件夹抽 3 条,拼接成 100 条成品(自动加转场+字幕)。
3. 自动发布:100 条批量发到抖音/快手。

### 示例 2:"解说类账号周更"(B → E)
1. 语音克隆出专属主播音色(一次)。
2. 每周写一段解说文案 → AI 剪辑(LLM 抽关键词 + CLIP 匹配素材 + 专属音色配音 + 字幕)。
3. 自动发布到 B站/视频号。

### 示例 3:"把直播回放做成系列短视频"(C → A → E)
1. AI 切片:把 2 小时直播切成带精彩度评分的片段。
2. 精选高分片段 → 随机混剪合并加转场。
3. 自动发布。

### 示例 4:"搬运参考节奏做原创解说"(D → E)
1. 影视解说克隆:参考节奏 + 自写文案 + 素材 + 专属音色。
2. 自动发布。

## 11. 文本精剪(可选精修步骤)

任何管线产出、或一条现成的口播/解说视频,只要"想删话、删口头禅、压停顿",都可以进「文本精剪」最后精修一遍:

1. 侧边栏进入「**文本精剪**」→ 选择口播视频 → 自动转写成句级文本。
2. **点着字剪**:点句子跳画面、悬停删句;一键「清理口头禅」「压缩停顿」。
3. (可选)💬 对话式改片:输入"删掉开头的废话,总长控制在 1 分钟内" → AI 给出可勾选的编辑计划 → 确认应用(需配置 LLM)。
4. 选择导出目录 →「按时间线导出」,系统自动校验导出结果与剪辑计划一致。

**何时用**:解说/口播、直播切片、课程录像——只要视频以"人说话"为主,剪完想再"去废话",就在发布前加这一步。原素材永不改动,剪错了撤销即可。

**典型组合**:
- 管线 B 出口播成片 → 文本精剪删口头禅 → E 自动发布。
- 管线 C 切出的高分片段 → 文本精剪掐掉头尾废话 → E 自动发布。

---

## 结语

生产一部成片 = **备料(分割/切片/准备) → 生产(混剪/AI剪辑/克隆) → 包装(配音/字幕/水印) → 发布(自动)**。

遇到不确定"下一步点哪个"时,回到本指南的**决策表**按自己的起点选管线,再按管线内的**数字顺序**一步步操作即可。
